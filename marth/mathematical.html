The Ambiguous Case

Interactive Worked Examples

Determine the number of triangles that can be formed with each set of measurements.

Worked Examples – Check Understanding4 items

Select the number of triangles first. Then check the answer, reveal a hint, or study the complete solution.

1
Given: A = 24°, a = 14, b = 27
▼
How many triangles can be formed?
Hint: Find B₁, then compute B₂ = 180° − B₁. Check whether both angle sums with A are less than 180°.
Complete Solution
  1. sin B / 27 = sin 24° / 14
  2. sin B = (27 sin 24°) / 14 ≈ 0.7844
  3. B₁ = sin⁻¹(0.7844) ≈ 51.67°
  4. B₂ = 180° − 51.67° = 128.33°
  5. A + B₁ = 24° + 51.67° = 75.67° < 180° ✓
  6. A + B₂ = 24° + 128.33° = 152.33° < 180° ✓
Answer: 2 different triangles exist.
2
Given: A = 126°, a = 28.5, b = 39.8
▼
How many triangles can be formed?
Hint: Calculate sin B = (b sin A)/a. A sine value greater than 1 is impossible.
Complete Solution
  1. sin B / 39.8 = sin 126° / 28.5
  2. sin B = (39.8 sin 126°) / 28.5 ≈ 1.1298
  3. Since a sine value cannot be greater than 1, sin⁻¹(1.1298) is undefined or gives an ERROR.
Answer: 0 triangles — NO triangle exists.
3
Given: A = 72°, a = 37.3, b = 32
▼
How many triangles can be formed?
Hint: Find both possible values of B. One angle sum will be valid and the other will exceed 180°.
Complete Solution
  1. sin B / 32 = sin 72° / 37.3
  2. sin B = (32 sin 72°) / 37.3 ≈ 0.8159
  3. B₁ = sin⁻¹(0.8159) ≈ 54.68°
  4. B₂ = 180° − 54.68° = 125.32°
  5. A + B₁ = 72° + 54.68° = 126.68° < 180° ✓
  6. A + B₂ = 72° + 125.32° = 197.32° > 180° ✕
Answer: Exactly 1 triangle exists.
4
Given: A = 70°, a = 30, b = 37
▼
How many triangles can be formed?
Hint: Calculate sin B = (b sin A)/a. Check whether the resulting sine value is possible.
Complete Solution
  1. sin B / 37 = sin 70° / 30
  2. sin B = (37 sin 70°) / 30 ≈ 1.1590
  3. Since a sine value cannot be greater than 1, sin⁻¹(1.1590) is undefined or gives an ERROR.
Answer: 0 triangles — NO triangle exists.
