1. Given f(x) = 2x + 3 and g(x) = x − 4, find (f ∘ g)(5).

Hint:
(f ∘ g)(5) = f(g(5)).
The symbol f ∘ g means f(g(x)). Therefore, evaluate g first. Find g(5), then use its output as the input of f.
Solution:
(f ∘ g)(5) = f(g(5))
g(5) = 5 − 4 = 1
f(1) = 2(1) + 3 = 5
Therefore, 5 is the correct answer.

2. Given f(x) = x² + 1 and g(x) = 3x, find (g ∘ f)(2).

Hint:
(g ∘ f)(2) = g(f(2)).
The symbol g ∘ f means g(f(x)). Therefore, evaluate f first. Find f(2), then use its output as the input of g.
Solution:
(g ∘ f)(2) = g(f(2))
f(2) = 2² + 1 = 5
g(5) = 3(5) = 15
Therefore, 15 is the correct answer.

3. Given f(x) = x + 2 and g(x) = x² − 1, which expression represents (f ∘ g)(x)?

Hint:
(f ∘ g)(x) = f(g(x)).
The symbol f ∘ g means that g is applied first. Replace the input x in f(x) with the entire expression g(x) = x² − 1.
Solution:
(f ∘ g)(x) = f(g(x))
= f(x² − 1)
= (x² − 1) + 2
= x² + 1
Therefore, A is correct.

4. Given f(x) = 2x − 1 and g(x) = x + 4, which statement is correct?

Hint:
(f ∘ g)(x) = f(g(x)) and (g ∘ f)(x) = g(f(x)).
For f ∘ g, evaluate g first. For g ∘ f, evaluate f first. Find both expressions separately and compare them. Remember that changing the order may change the result.
Solution:
(f ∘ g)(x) = f(g(x)) = f(x + 4) = 2(x + 4) − 1 = 2x + 7

(g ∘ f)(x) = g(f(x)) = g(2x − 1) = (2x − 1) + 4 = 2x + 3

Therefore, B is correct.

5. A delivery fee is determined in two steps. First, the distance x in kilometers is converted to a base charge using g(x) = 10x + 20. Then a service fee of ₱15 is added using f(x) = x + 15. What is the total charge for a delivery 6 km away?

Hint:
The base charge is found first using g, and then the service fee is added using f. Therefore, the situation is represented by (f ∘ g)(6) = f(g(6)).

Remember: (f ∘ g)(x) = f(g(x)), so g is evaluated first. Find g(6), then use its output as the input of f.
Solution:
(f ∘ g)(6) = f(g(6))
g(6) = 10(6) + 20 = 80
f(80) = 80 + 15 = 95
Therefore, the total delivery charge is ₱95.
